# EasyStudy (EZstudy)

EasyStudy — Flutter-приложение для подготовки по билетам в игровом формате: карта уровней, прогресс по вопросам, награды, магазин оформления и достижения.

Документация в этой ветке актуализирована по состоянию ветки `dev` на 7 апреля 2026.

## Что уже реализовано
- Карта из 25 билетов с пошаговой разблокировкой.
- Экран билета с теорией, прогресс-баром и переходом к вопросам.
- Сценарий решения подвопросов с повторными попытками и объяснениями.
- Итоговый экран статистики по билету (точность, ошибки, слабые места).
- Достижения с наградами в монетах.
- Магазин фонов с покупкой за внутриигровую валюту.
- Глобальная статистика по другим аккаунтам (после входа и подтверждения email).
- Настройки звука, музыки, вибрации, темы (`Classic`/`Pulse`) и режима темы (`system/light/dark`).

## Аккаунт и синхронизация
- Используются Firebase Authentication и Cloud Firestore.
- Регистрация отправляет письмо подтверждения email.
- Вход разрешен только после подтверждения email.
- Прогресс синхронизируется автоматически:
  - при изменениях локального состояния (debounce),
  - периодически (раз в 5 минут),
  - при уходе приложения в фон.
- При выходе из аккаунта локальный прогресс сбрасывается.

## Текущие ограничения
- Контент вопросов сейчас загружается из одного файла: `assets/questions/software_engineering.json`.
- В модели состояния есть несколько предметов (`chemistry`, `math`, `history`), но в текущем UI доступен только один фактический набор контента.
- В проекте остался legacy FastAPI backend (`backend/*`) и `lib/data/backend_client.dart`, но основной клиентский поток сейчас работает через Firebase.

## Платформы
- Поддерживаются: Android, iOS, Web, macOS, Windows.
- Linux в текущей конфигурации FlutterFire не настроен (`DefaultFirebaseOptions` бросает `UnsupportedError` для Linux).
