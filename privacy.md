# Политика конфиденциальности EasyStudy

Дата вступления в силу: 7 апреля 2026

## 1. Общие положения
Настоящая политика описывает, какие данные обрабатываются в приложении EasyStudy (далее — «Приложение») и для каких целей.

## 2. Какие данные обрабатываются
### 2.1 Данные аккаунта
При регистрации и входе через Firebase Authentication обрабатываются:
- email;
- технический идентификатор пользователя (UID).

### 2.2 Игровые данные
Приложение сохраняет прогресс и настройки:
- локально на устройстве (`SharedPreferences`);
- в облаке (Cloud Firestore), если пользователь авторизован.

В облачный конфиг могут входить:
- уровень, опыт, монеты;
- прогресс по билетам;
- достижения;
- настройки звука/темы;
- выбранные элементы кастомизации;
- накопленное игровое время.

## 3. Цели обработки данных
- авторизация пользователя;
- синхронизация прогресса между устройствами;
- отображение глобальной статистики по билетам.

## 4. Сторонние сервисы
Приложение использует сервисы Firebase:
- Firebase Authentication;
- Cloud Firestore.

Передача данных осуществляется только в объеме, необходимом для работы функций аккаунта и синхронизации.

## 5. Доступ к функциям устройства
Приложение не запрашивает доступ к контактам, фото, геолокации и другим чувствительным данным устройства.

## 6. Хранение и удаление
- Локальные данные удаляются при сбросе прогресса внутри приложения.
- Облачные данные хранятся в Firestore в рамках аккаунта пользователя.

## 7. Изменения политики
Политика может обновляться. Актуальная версия всегда доступна в этом файле.
